# gearbox-design-calculator

Mechanical design tool for spur gearbox - ratio, torque, shaft and stress calculation.

## Features
- Calculate gear ratio
- Calculate output speed (RPM)
- Calculate output torque
- Shaft design calculation
- Stress calculation for spur gears

## Files in This Project
- `gearbox_calculator.py` - Main calculator program
- `README.md` - Project description

## How to Use
1. Open `gearbox_calculator.py`
2. Run the program
3. Enter input speed, torque, and gear teeth
4. Get your result
